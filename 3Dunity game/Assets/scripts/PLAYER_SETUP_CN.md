# 玩家角色替换说明

你当前场景里有两个不同概念的角色：

- `Character.001`：真正的玩家对象，带控制器、碰撞、相机、`Player` 标签
- `Character_Female_Gypsy_01`：普通放在场景里的女性角色 prefab，不是当前可控制玩家

所以如果你直接运行，游戏控制的通常还是 `Character.001`，不是单独那个女性角色。

## 正确做法

不要把女性角色当成第二个玩家单独放在场景里。

应该把女性角色作为“玩家外观模型”挂到真正的玩家对象上。

## 最推荐的接法

### 1. 找到真正玩家

在 Hierarchy 里找到当前玩家对象：

- 通常名字是 `Character.001`
- 它应该带有 `Player` 标签
- 它身上会有角色控制器、碰撞体、相机相关组件

### 2. 把场景里的独立女性角色删掉或禁用

如果场景里有单独的 `Character_Female_Gypsy_01`：

- 先不要拿她当玩家
- 可以先禁用，避免画面里出现两个角色

### 3. 把女性角色 prefab 拖到玩家对象下面

从 `Project` 里找到：

- `Assets/PolygonFantasyCharacters/Prefabs/Character_Female_Gypsy_01.prefab`

把它拖到 `Character.001` 下面，作为子物体。

### 4. 重置女性角色子物体的位置

选中这个新的女性角色子物体，设置：

- `Position = (0, 0, 0)`
- `Rotation = (0, 0, 0)`
- `Scale = (1, 1, 1)`

如果模型太大或太小，再微调 `Scale`。

### 5. 禁用旧外观

如果 `Character.001` 下面原来已经有老的模型外观：

- 只禁用老模型显示物体
- 不要删角色控制器、碰撞器、脚本、相机

## 可选脚本

项目里新增了一个辅助脚本：

- `PlayerVisualAttachment.cs`

用途：

- 自动把新的外观模型保持在玩家对象下面
- 可选地禁用旧外观

### 用法

挂到 `Character.001` 上，然后：

- `Visual Root` 拖入新的女性角色子物体
- `Old Visual To Disable` 拖入旧模型显示物体

## 必须确认的条件

- 真正的玩家对象才有 `Player` 标签
- `MissionManager` 不要再使用 `Player` 标签
- 场景里不要同时存在两个都想当玩家的对象

## 如果运行时角色“消失”

优先检查这几项：

1. 游戏暂停后看 Hierarchy 里玩家对象是否还在
2. 看玩家对象 `Transform` 的 `Y` 是否不断下降
3. 看相机是否跟着真正的玩家对象
4. 看新女性角色是不是只是普通场景物体，而不是玩家子物体
